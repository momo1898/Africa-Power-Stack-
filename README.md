# Africa Power Stack

**How power is built in Africa, and how it can be rebuilt.**

An interactive, non-commercial educational guide to how political power works across much of Africa: who holds it, how money, force, votes and approval move between actors, how the system defends and reinforces itself, and how every role can help change it.

- 74 careers and voter types, each placed in the system
- Country types and an interactive map of all 54 countries
- Real case studies: Libya 2011, Cameroon 2025, Senegal 2024, Zambia 2021–2026
- A comparison of China's and Africa's development journeys
- Available in English, French, Portuguese, Swahili, Arabic, Simplified Chinese and Nigerian Pidgin

Live site: https://africapowerstack.org

This is an independent project. It is not affiliated with, funded by or endorsed by any government, political party, employer or international organization.

The whole site is a single self-contained `index.html`.
